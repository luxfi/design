# content — the words

Tokens decide how a Lux surface looks. Content decides what it says. Same
discipline, applied to language: one voice, held everywhere.

| File | What |
|------|------|
| [`voice.md`](voice.md) | How Lux speaks — the rules, with before/after copy. |
| [`taglines.md`](taglines.md) | Approved headline and tagline lines, by surface. |

The atom is the same one that governs the visual system: **understated.** The
product is the frontier; the copy does not need to shout about it. Numbers over
adjectives. No exclamation marks. No emoji.
